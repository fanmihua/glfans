# 关于页徽章 3D 查看器

点击关于页原有徽章，打开 550 × 650px 的居中展示窗；手机按可用视口与安全区域缩小。默认正面静止，桌面和常见竖屏手机上，徽章约占展示窗宽度的 56%。鼠标或单指拖拽旋转，滚轮或双指捏合缩放，底部按钮用于放大、缩小、恢复正面与初始大小。打开时锁定背景滚动，支持 Esc、关闭按钮与遮罩关闭，并恢复原位置和入口焦点。

桌面、平板的信纸徽章和手机的标题旁徽章共用入口行为。鼠标悬停时，图片以 `200ms ease-out` 平滑放大至 `1.2` 倍，移开后复原。缩放作用于图片，按钮边界固定。动效适用于支持悬停且允许动态效果的环境，键盘焦点通过粉色描边标示。布局断点见[关于页交接](./ABOUT_PAGE_HANDOFF.md)。

如需重新生成网站模型副本，使用原始 GLB 运行：

```sh
node scripts/import-about-badge.mjs /path/to/original/badge.glb
```

该导入器针对本次 Vector to 3D 徽章的导出结构，写入 `public/assets/about/` 并输出带内容哈希的文件名。替换模型时同步更新关于页地址和模型测试中的哈希；不要把已经转换的网站副本再次作为输入。

## 加载与错误处理

`BadgeViewerDialog` 接收 `modelUrl`、`posterUrl`、三语文案、关闭回调及入口引用。首次打开才动态导入 `@google/model-viewer` 与 Three.js；没有自动旋转、AR 或模型下载入口。3D 代码是独立资源，不进入关于页的初次下载。

显示预览图与真实加载进度；模型或照明加载错误、30 秒超时和缺少 WebGL2 能力时显示图片兜底及重试。重试绕过查看器的模型失败 URL 缓存。关闭或路由卸载后移除事件、计时器与模型节点，停止绘制；关闭期间迟到的加载结果不能重新挂载。

## 验证方式

```sh
npm ci
npx playwright install chromium webkit
npm run test:badge
node --test tests/*.test.mjs
npm run test:server
git diff --check
```

`test:badge` 先生产构建，再运行桌面 Chromium、Pixel 7 Chromium 模拟和 iPhone 13 WebKit 模拟。测试包括按需加载、默认静止、旋转俯仰、缩放边界、复位、焦点与滚动恢复、失败与超时重试、加载途中关闭、三语提示和微信 UA；Android 模拟通过浏览器原生多点触控事件验证捏合，其余项目不重复该平台专用测试。

项目没有配置独立 lint。服务端隔离 MySQL 测试在没有配置测试数据库时按既有规则跳过。模拟设备和微信 UA 验证不能替代 iPhone、安卓及微信的真机验收。

2026-11-06 完成最终本地验证。生产构建、317 项项目测试、28 项浏览器测试、15 项服务端测试和差异检查通过。Android 捏合用例在另外两个浏览器项目按条件跳过。服务端有 1 项 MySQL 测试因缺少隔离测试库配置而跳过。

在本地开发预览的 1440、820 和 393px 视口实测徽章图片放大 20%、移开复原及按钮边界固定，验证点击、Esc、焦点恢复、触屏和减少动态效果设置。3D 查看器另核对了 320 × 568 小屏、844 × 390 横屏、背面文字及四个图标的 24 × 24px 尺寸。

全量验证同时修复了既有日历构建测试用 `URL.pathname` 启动脚本时无法识别中文与空格目录的问题：改用 `fileURLToPath`，不改变日历产品行为。
