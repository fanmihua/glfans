# 飞书反馈实现记录 · 2026-10-16

来源：[glfans-优化建议](https://my.feishu.cn/wiki/XSV5w8MLiizcFjkotq3cK14VnCd)，修订 1230，「新需求2026/10/10」。用户确认留言回复不做、点赞可做、日历导出可做，其余实施。

## 实现范围

- 原话投稿和评论最多 80 个 Unicode 字符，显示实时字数。既有长内容保留全文；超过 50 字默认预览，桌面悬停或键盘聚焦查看，手机粉色展开/收起。
- 评论支持点赞和取消，按匿名身份持久化；重复请求幂等，审核隐藏或删除后不可继续点赞。读取响应不会覆盖请求期间刚完成的点赞。未增加回复层级或通知。
- 日历按当前月份以及全部、关注、CP 或单剧范围导出 `.ics`。已知时刻使用 UTC，无时刻的日期使用全天事件；不推断结束时间或提醒，导入后不会自动更新。
- 持续订阅同时支持全部剧集与自选多部剧，独立于浏览月份和浏览器关注列表。网站提供 Apple 日历入口及可复制 HTTPS 链接，改选后用新链接替换旧订阅；三语同步。构建生成全部已确认排期，API 在静态版本切换后读取新内容。
- AndaLookkaew 补《镇灵》副 CP 与双向关联；IzeMarissa 复用旧路由并补 Blank 两季；新增 MewRenee、ViewJune、JuneMewnich、NoonPraewa、ShuMook、TubtimFilm。
- 《深宫幽情》共 30 集正片，保留《月下禁爱》等别名，接入中英泰档案、搜索、CP 和日历。30 条历史排期逐集取自 Thai PBS；EP5 时刻冲突保留未知。详见 [剧集核对](archive-20261016.md) 与 [CP 核对](cp-20261016/README.md)。
- 新增 8 张真实 CP 主图和 1 张官方剧集海报，压缩为 WebP；缺项及官方结束合作证据不足时保持待核实。

- `npm run test:sites`：4 项通过（同样包含在上述 294 项中）。

- 日历在 1440×900 与 360×800、中英泰界面实际下载并读回：全部排期 24 条，关注《镇灵》及 AndaLookkaew 范围各 4 条；空关注禁用、键盘下载通过。
