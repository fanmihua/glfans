## 已实现行为

### CP 页

- 搜索框 `border-radius` 从 `24px` 改为 `0`。
- PC 与移动端共用 `.cp-search`，因此两端同步生效。

### CP 移动端筛选覆层

- 实现依据为 Figma 文件 `GL-repo` 的“筛选控件修改”画板（节点 `144:3270`）。
- 点击“切换 CP”后，原先从屏幕底部升起的抽屉改为从筛选条下沿向下展开；进入动画由 `translateY(-24px)` 回到原位，减少动效偏好下取消动画。
- 展开时读取 `.cp-directory--mobile` 的实际底边并写入 `--cp-directory-top`，因此面板既能跟随页面中的筛选条，也能在筛选条吸顶后准确衔接其下方。
- 模态层内同步渲染打开态筛选条，避免锁定页面滚动时原 sticky 筛选条移出可视区域；打开态箭头向上，点击该筛选条也可关闭目录。
- 面板继续保留“全部 CP”、统计、搜索和双列 CP 卡片；卡片间距、字号、面板粉色底边与画板一致，列表内容在面板内部滚动。
- 面板下方为 50% 黑色蒙版。点击面板外区域（包括下方蒙版）会关闭覆层；按 `Esc`、选择 CP 或点击打开态筛选条也会关闭，随后焦点返回原筛选按钮。
- 页面打开期间锁定根节点和 `body` 的滚动，关闭后恢复此前的 overflow 值。桌面 CP 目录交互不受本次修改影响。

### 考古档案日历入口

- 考古档案首页的“查看播出日历”主按钮取消 `rotate(-1.4deg)`，按钮、图标和文字保持水平。
- 年份二级页标题区的同名主按钮取消 `rotate(-1.5deg)`；剧集摘要区的日历入口显式设置 `transform: none`，防止被后续共享样式带入倾斜。
- 年份二级页保留“返回年份”纸片按钮自身的轻微倾斜，并补偿旋转后的视觉偏移，使其左边缘与标题区“查看播出日历”按钮左边缘对齐；桌面与移动端分别校准。
- 修改同时覆盖桌面与移动端，不改变按钮尺寸、颜色、图标、聚焦状态或打开日历的行为。

### REPO 合集页

- 合集入口卡片封面默认显示原始彩色。
- 卡片悬停仍保留轻微缩放，取消由黑白变彩色的滤镜变化。
- “宿敌恋人”合集资料信息块取消整体倾斜，图标、文字和分隔线水平显示。

### REPO 二级目录卡片

- 合集二级目录 `#/column/:collectionSlug` 中的文章入口卡片默认统一去色，作用域限定为 `.collection-collage + .article-index`。
- 删除第二张卡片原有的单独彩色覆盖，全部卡片默认使用 `grayscale(0.82) contrast(1.08)`，避免同一目录中出现默认色彩不一致。
- 鼠标悬停或键盘聚焦时仍使用 `grayscale(0.15) contrast(1.02)` 并轻微缩放，不改变原有交互反馈。
- 此规则不影响 REPO 专栏首页默认彩色的合集封面，也不影响正文文章中默认彩色的图片。

### REPO 正文标题

- 合集标题和文章标题改为同一行、基线对齐，并保持不主动换行。
- 粉色手绘装饰线移动到文章标题内部，只跟随文章标题宽度。
- 响应式字号和间距分别适配桌面、平板与移动端。
- 标题区取消固定最小高度，按内容自然撑开；底部留白包含装饰线高度，使正文整体上移。
- `rival-lover/wine-ep06-07` 不再在标题区重复展示首张图片，首图保留在正文内容中。

### REPO 正文图文布局

- `rival-lover/wine-ep06-07` 增加 `article-magazine--paired` 页面标识。
- 该文章在桌面端使用等宽两栏：图片始终在左，文字始终在右，不再交替方向。
- 右侧文字块与左侧整组图片垂直居中，即两者中心落在同一水平线上；段落文本仍按原有方式排版。
- 连续图片顺序排列，取消倾斜、错位和负边距重叠。
- 桌面端连续图片使用 `gap: 10px`；平板和移动端通过高优先级 `:nth-child(n)` 规则清除旧负上边距，最终图片边界间距同样为 10px。
- 移动端保留图片在上、对应文字在下的单栏阅读顺序。

### REPO 正文图片和滚动效果

- `.article-magazine` 内正文图片和标题图片使用原始彩色，取消灰度与去饱和滤镜。
- 取消正文图片悬停缩放及滤镜变化。
- `ArticleView` 不再启用 `useArticleReveal`，因此图文区块不会随滚动淡入、平移、旋转、缩放或变色。
- 顶部阅读进度条仍正常随滚动更新。

### REPO 正文段落间距

- 桌面正文段落下间距从 `1.38em` 减少 12px，最终为 `calc(1.38em - 12px)`；16px 字号下浏览器计算值为 10.08px。
- 手机端正文段落下间距为 4px。
- 图片间距、段落间距和图文分组间距仍分别管理。

## 作用域说明

写入 `AGENTS.md` 的规则分为两个独立作用域：二级目录卡片规则只约束 `#/column/:collectionSlug`，样式以 `.collection-collage + .article-index` 为作用域；正文排版规则只约束 `#/column/:collectionSlug/:articleSlug`，样式以 `.article-view.article-magazine` 为主要作用域。

分支还包含用户此前单独确认的 CP 搜索框、CP 移动端筛选覆层和 REPO 合集页改动。这些不是正文规则的扩展，而是同一分支中需要一并交接的独立 UI 修改。CP 覆层只在 `useMobileLayout()` 命中的移动端渲染，相关样式以 `.cp-directory-dialog`、`.cp-directory-dialog-bar` 和 `.cp-directory-panel` 为作用域。

当前左图右文的两栏布局通过文章标识精确限定到 `rival-lover/wine-ep06-07`。标题、正文图片彩色、滚动效果和正文段落间距应用于 REPO 正文文章模板。管理员若计划让后续文章也采用两栏布局，应将 `article-magazine--paired` 的启用条件改为内容配置或文章元数据，不建议继续追加硬编码 slug。

## 合并方式

推荐合并整个本地分支：

```bash
git switch main
git merge --no-ff ui-layout-adjustments
```

如管理员只希望挑选提交，应先将当前工作树中的二级目录去色、CP 移动端筛选覆层、考古档案日历入口、规则和文档更新提交，再按顺序挑选相关提交。当前前三个已提交记录为：

```bash
git switch main
git cherry-pick 88dfa3a 1802365 91767d0 <本次修改提交哈希>
```

合并后再次执行生产构建与完整测试。如果目标 `main` 已更新，应先基于最新 `main` 检查 `ArticleView.jsx`、`magazine.css` 和 `mobile-article.css` 的冲突与样式顺序；其中移动端 `:nth-child(n)` 的优先级用于覆盖旧的偶数图片负上边距，解决冲突时不能误删。
